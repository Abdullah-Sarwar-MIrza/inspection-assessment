A QUICK WALKTHROUGH
From image to insight.
  1. Choose a casting image.
    Upload a JPG or PNG, drag it onto the page, or select a reference image.
  2. Run the inspection.
    The model returns Normal or Defective. Reference images run automatically when selected.
  3. Review the result.
    The defect score is compared with the saved threshold. Download the response using Save result.
This model was evaluated on a supplied casting dataset. New cameras, lighting and products need separate validation. It does not recognize unrelated images or locate individual defects.
